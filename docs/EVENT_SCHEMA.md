# Event schema

Source of truth: `packages/contracts/src/events.ts`. Everything below is enforced by Zod on the server.

## Envelope

```ts
{
  v: 1,
  sessionId: string,       // uuid generated by the SDK, persisted per tab
  batchSeq: number,        // 0-based, unique per session; retries reuse it
  sentAt: number,          // epoch ms
  meta?: SessionMeta,      // required on the first batch
  events: RecordedEvent[], // at most 2000
  final?: boolean          // true on the last batch of a session
}
```

Limits (`LIMITS` in `packages/contracts/src/limits.ts`): 2 MB decompressed per batch, 2000 events per batch, 2000 characters per message, 8000 per stack, 2048 per URL, 500 per captured input value, 120 per element text, 10 console args.

## Session metadata

| Field | Notes |
| --- | --- |
| `startedAt` | epoch ms |
| `sdkVersion` | SDK package version |
| `release`, `environment` | set by the application |
| `browser.name`, `browser.version`, `browser.userAgent` | parsed from the user agent |
| `os` | best effort from the user agent |
| `viewport.width`, `viewport.height`, `viewport.devicePixelRatio` | at start |
| `page.url`, `page.title`, `page.referrer` | URLs are sanitised |
| `locale`, `timezone` | from `navigator` and `Intl` |

## Events

Every event has `seq` (monotonic per session across page loads), `ts` (epoch ms) and `type`.

| Type | Data | Captured from |
| --- | --- | --- |
| `rrweb` | rrweb `eventWithTime` | `rrweb.record` with masking options |
| `click` | `target: ElementDescriptor`, `x`, `y` | `click` listener, capture phase |
| `input` | `target`, `kind` (text, textarea, select, checkbox, radio, other), `value` (null when masked), `masked`, `checked` | `change` listener |
| `submit` | `target` (the form) | `submit` listener |
| `navigation` | `url` (sanitised), `kind` (load, push, replace, pop, hash), `title` | initial load, patched `history`, `popstate`, `hashchange` |
| `error` | `kind` (exception, unhandledrejection, captured), `name`, `message`, `stack`, `handled`, `source`, `line`, `column`, `context` | `window.onerror`, `unhandledrejection`, `captureException` |
| `console` | `level` (error, warn), `args: string[]` | wrapped `console.error` and `console.warn` |
| `network` | `kind` (fetch, xhr), `method`, `url`, `path`, `status`, `ok`, `durationMs`, `error`, `requestId` | patched `fetch` and `XMLHttpRequest` |
| `annotation` | `name`, `data` | `Repro.annotate` |
| `identify` | `userId`, `traits` | `Repro.identify` |

## Element descriptor

Attached to click, input and submit events. Contains only stable, human-meaningful attributes: `tag`, `testId`, `id`, `name`, `type`, `role`, `accessibleName`, `label`, `placeholder`, `text`, `href`, `ariaLabel`, `autocomplete`, `cssPath`, `sensitive`, `formId`, `formTestId`. It never contains rrweb node ids or the control's value.

## Storage

Each batch becomes one `event_chunks` row: `batch_seq`, `first_seq`, `last_seq`, `event_count`, `encoding` (`gzip`), `location` (`inline`), `byte_size`, `payload` (gzip of the JSON event array). Readers order by `batch_seq` and deduplicate by `seq`.

## Evolution

`v` is the schema version. A new event type is additive: old readers ignore unknown `type` values in the dashboard, and the server rejects them until its contracts package is updated, which is the intended behaviour for an untrusted input boundary.
